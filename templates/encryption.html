Workflow Explanation:
  1. The device payload is divided into 16-bit data blocks (m_i).
  2. The Substitution-Permutation Network (SPN) encrypts the block using the previous hash (H_{i-1}) as the key.
  3. The resulting ciphertext is XORed with the original message block to produce the next hash (H_i).
  4. This Matyas-Meyer-Oseas construction ensures collision resistance and data integrity in the Zero Trust Network.
